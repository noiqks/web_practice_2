MD5 File Hasher



Реализовать HTTP API для выполнения вычислительных задач согласно теме

курсовой работы. Для хранения данных на диске в веб-приложении используется

файловая система управления базами данных (СУБД). Необходимо обеспечить

поддержку управления данными через HTTP API



MD5 File Hasher — консольная утилита на Python для вычисления MD5-хеш-суммы файла. Программа принимает путь к входному файлу и путь для сохранения результата.



Проект выполняется в рамках практической работы № 2, вариант № 10.
